# 百度贴吧账号管理工具

基于 [aiotieba](https://github.com/starkzarn/aiotieba) 的命令行小工具，用于查看和管理自己贴吧账号下**屏蔽的吧**与**拉黑的用户**。

## 功能

- 查看 / 解除屏蔽的吧（可单个、范围、多选、全部）
- 查看 / 解除新版拉黑用户
- 查看 / 解除旧版黑名单用户
- BDUSS 本地保存，下次启动免重复输入；支持一键清除重新登录

## 环境要求

- Python 3.10 及以上

## 安装

```bash
# 克隆或下载本项目后进入目录
cd tieba-manager

# 建议使用虚拟环境
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
# source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

## 获取 BDUSS

工具通过浏览器 Cookie 中的 `BDUSS` 完成登录，**不会上传你的账号密码**。

1. 在浏览器中登录 [百度贴吧](https://tieba.baidu.com)
2. 按 `F12` 打开开发者工具
3. 顶部标签栏选择 **「应用程序」/ Application**
   （如果没看到，点标签栏右侧的 `>>` 或右上角菜单 → 更多工具 → 应用程序）
4. 左侧找到 **Cookies** → 展开 → 点击 `https://tieba.baidu.com`
5. 在名称列表中找到 **BDUSS**，复制它的值（双击值列 → 全选复制）

> BDUSS 等同于登录凭证，**请勿泄露给他人、不要提交到公开仓库**。

## 使用

```bash
python tieba_manager.py
```

首次启动会提示粘贴 BDUSS，随后进入主菜单：

```
  1. 查看屏蔽的吧
  2. 解除屏蔽的吧
  3. 查看拉黑的用户（新版）
  4. 解除拉黑的用户（新版）
  5. 查看旧版黑名单用户
  6. 解除旧版黑名单
  7. 重新登录（清除已保存的 BDUSS）
  0. 返回/退出
```

解除操作的选择方式：

| 输入 | 含义 |
|------|------|
| `1` | 解除第 1 个 |
| `1 3 5` | 解除第 1、3、5 个 |
| `1-5` | 解除第 1 到第 5 个 |
| `all` | 解除全部（需二次确认） |

## 配置文件位置

BDUSS 仅保存在本机用户目录下，不在项目目录中：

- Windows: `C:\Users\<用户名>\.tieba_tool\config.json`
- macOS / Linux: `~/.tieba_tool/config.json`

## 常见问题

**提示“用户未登录或登录失败”？**
BDUSS 已过期或在浏览器退出了账号。重新登录贴吧后，按上面的步骤复制新的 BDUSS，在菜单选「重新登录」替换即可。

**会被封号吗？**
本工具只读取和修改你自己账号的屏蔽 / 黑名单设置，操作间隔默认 1 秒。请勿用于批量发帖、刷量、骚扰他人或高频自动化操作，自行遵守贴吧社区规则。
